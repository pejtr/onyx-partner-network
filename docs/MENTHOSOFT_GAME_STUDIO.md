# MENTHOSOFT Game Studio

**MENTHOSOFT** is the game-development and interactive-experience studio in the ONYX ecosystem.

Its commercial role is to turn internal game prototypes, browser technology and creative concepts into:

- original games and playable IP;
- branded advergames and interactive campaigns;
- browser-based 2D/3D experiences;
- gamification for ONYX business sites;
- multiplayer prototypes;
- AI characters and adaptive game systems;
- game-development services for external clients.

## Stargate / Jaffa IP boundary

The Stargate/Jaffa project is useful as a historical and technical portfolio artifact, but third-party names, characters, logos, art, audio and other protected material must not be sold or presented as owned ONYX/MENTHOSOFT IP without the required rights.

For commercial reuse, extract the **gameplay mechanics and engineering lessons** into an original universe with original names, art, narrative and audio.

## Commercial product lines

### 1. Original games
MENTHOSOFT-owned browser, desktop or mobile-compatible properties.

**Revenue:** premium purchase, subscriptions, DLC/content, sponsorship, in-game purchases where appropriate.

### 2. Advergames
Short, high-impact games for brands, launches, events and campaigns.

**Revenue:** fixed production fee + optional hosting/analytics/maintenance retainer.

### 3. Interactive web experiences
3D product worlds, mini-games, campaign microsites, interactive storytelling and gamified lead-gen.

**Revenue:** project fee + ONYXWEB / ONYX.Agency upsell.

### 4. Gamification modules
Reusable mechanics for the wider ONYX network: XP, quests, achievements, loyalty, challenges, leaderboards and rewards.

**Revenue:** ONYXWEB module subscription or enterprise implementation.

### 5. AI game systems
AI NPCs, procedural missions, narrative assistants, moderation and dynamic content routing.

**Revenue:** usage credits, premium module, client implementation.
